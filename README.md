# Waver

CLI utitity to read a raw wave file, created with
```bash
ffmpeg -i <input.mp3> -ac 1 -ar <rate> -f s16le <output.raw>
```

It can write a .csv file that can be viewed with `https://www.rawgraphs.io/`.
